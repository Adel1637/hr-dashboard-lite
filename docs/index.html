What the free edition does

Everything you need to go from the export your payroll software gives you to a dashboard your team can open.

  • Excel and CSV import

    Header row, separator and encoding are detected. A title line or blank lines above the data are fine.

  • A mapping step that remembers

    Recognises headers such as “Hire date”, “Date d'embauche” or “Grade”, and keeps your choices for the next import.

  • Exact line numbers

    Each error in the report carries the row number Excel shows, even with blank rows before or between the data.

  • Headcount module

    Headcount at a date and its change, permanent-contract share, monthly trend, split by department, site and category.

  • Global filters

    Reference date, period, site, department, category, contract and sex, applied everywhere at once.

  • A data table that scales

    Search, sort and pagination run on the server. Tested on 20,000 employees: import and validation take under a second.

  • Security included

    Passwords hashed with scrypt, JWT sessions, login rate limiting, strict Content-Security-Policy, no secret in the code.

  • Yours to brand

    Light and dark themes, French and English, your colour and logo, and a layout that works on a phone.

Run it in five minutes

You need Python 3.11 or newer, or Docker.

  1. Download and install

    Clone the repository, create a virtual environment and install the dependencies.

  2. Set your secrets

    Copy .env.example to .env and set ADMIN_PASSWORD. If you leave it empty, a random password is printed once when the app first starts.

  3. Create demo files

    Generates fictional files of 50, 1,000 and 20,000 employees.

  4. Start and import

    Open localhost:8000, sign in as admin and import demo_data/personnel_demo_1000.xlsx.

git clone https://github.com/Adel1637/hr-dashboard-lite.git
cd hr-dashboard-lite
python -m venv .venv && source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# set ADMIN_PASSWORD (and JWT_SECRET for production)

python demo_data/generate.py

uvicorn app.main:app --reload
# open http://localhost:8000

Prefer Docker? Run: docker compose up -d --build

Questions

Is the Lite edition really free?

Yes. It is MIT-licensed, so you can use it personally or commercially, modify it and deliver it to clients.

Does my data leave my server?

No. The app runs on your machine or network, stores imports in its data folder and needs no Internet connection. The font is bundled and there is no tracking.

What does my file need?

An .xlsx or .csv file with one row per employee, present or departed. Only two columns are required: an employee ID and a hire date. Everything else is optional, and the mapping step matches your headers.

What happens when a row is wrong?

The import report lists each problem with its Excel row number and says whether the row was rejected or the value ignored. Typical causes: an exit date before the hire date, an unreadable date, an empty ID.

How big can the file be?

The default limit is 25 MB (MAX_UPLOAD_MB in .env). A fictional company of 20,000 employees imports and validates in under a second.

How do I change the colour, logo or language?

In the .env file: APP_NAME, APP_ACCENT, APP_LOGO and APP_DEFAULT_LANG. Restart the app to apply them.

Can I use Lite on a client project?

Yes, the MIT licence allows it. The Pro modules (turnover, demographics, training, exports, users and audit log) are what Pro adds.

How do I report a bug or ask for a feature?

Open an issue on GitHub. Bug reports with a small sample file are the easiest to fix.
